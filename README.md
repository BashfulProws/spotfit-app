# SpotFit (class prototype)

Shopper-facing prototype for the Services Marketing Phase 2 project (Group 4, GIM). Find nearby apparel in your size, compare price and offers, ask a branch for a missing size, request a 1 or 2 hour hold, and finish with a pay-at-store pickup.

Live demo: https://bashfulprows.github.io/spotfit-app/

All stores, stock, prices and replies are sample data. No payments, no real retailers.
